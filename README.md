# samples-react

React + TypeScript の制作サンプル集。公開先は GitHub Pages。

## サンプル

### 撮影スタジオ 予約管理画面

レンタル撮影スタジオの予約を管理する画面。**架空の題材であり、実在の企業・団体・個人とは関係しません。**

- 公開URL: https://norio-io.github.io/samples-react/booking/photo-studio-admin/
- ソース: `apps/booking/photo-studio-admin/`
- 対応する静的サンプル: [`norio-io/samples`](https://github.com/norio-io/samples) の `booking/photo-studio/`（同一題材の予約サイト）

#### 画面構成

| 画面 | パス | 内容 |
|---|---|---|
| 予約一覧 | `/` | 絞り込み・並び替え・ページング。検索条件をURLに保持する |
| 予約詳細 | `/reservations/:id` | 全項目の表示とステータス遷移 |
| 予約登録 | `/reservations/new` | 入力値検証と重複予約の検出 |

#### 実装した事項

- **検索条件のURL保持** — 絞り込み・並び順・ページ番号をすべてクエリパラメータへ保持する。再読み込み、ブラウザの戻る・進む、URLの共有のいずれでも同一の結果を復元する。既定値はURLへ出力せず、不正な値や未知のパラメータは既定値へフォールバックする
- **非同期状態の表示** — 読込中は一覧と同じ形状のプレースホルダを表示し、条件変更による再取得中は直前の結果を保ったまま更新中であることを示す。エラーは原因と再試行の手段を提示し、該当なしは絞り込みの解除手段を併せて示す。古い応答が新しい応答を上書きしない
- **楽観的更新** — ステータスの変更は応答を待たずに反映し、失敗時は直前の状態へ復元する。復元は一覧の表示にも及ぶ
- **ステータス遷移規則** — 単一の定義に集約し、画面のボタン表示とデータアクセス層の双方が参照する。復旧できない操作は確認を求める
- **入力値検証** — 送信時に検証し、最初の誤りへ焦点を移す。エラー文言は入力欄と関連づける。重複予約はデータアクセス層でも判定し、重なっている既存の予約を提示する
- **アクセシビリティ** — キーボードのみで操作できる。確認は焦点を内側に捕捉し、Escape で閉じ、背面を不活性化する。状態変化は支援技術へ通知する。ステータスは文字で示し、色のみで区別しない

#### 技術的な前提

- 外部サーバーを持たないため、データアクセス層はブラウザ内で完結するモックとして実装している（応答遅延・失敗の再現を含む）
- 初期データは乱数を用いず決定的に生成する。顧客名・連絡先はすべて架空の値

## 開発

```sh
npm ci
npm run dev -w @samples-react/photo-studio-admin   # 開発サーバー
npm run typecheck
npm run lint
npm run test
npm run build                                      # dist/ へ出力
```

構成および開発上の取り決めは [CLAUDE.md](./CLAUDE.md) を参照。
